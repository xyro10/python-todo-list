# python-todo-list
A simple Python To-Do List application that stores tasks in a CSV file and allows users to create, view, and delete tasks.

## Features
- Add tasks
- Remove tasks
- Display tasks
- Save tasks to CSV
- Load tasks from CSV

## Concepts Used
- Object Oriented Programming (OOP)
- File Handling
- CSV Processing
- Exception Handling

## Future Improvements
Possible features for future versions:
- Add task completion status
- Add task deadlines
- Add task search functionality
- Sort tasks by priority
- Improve command-line interface
